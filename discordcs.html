Discord Classic Style

Last updated: March 31st, 2025

JavaScript userscripts gui theme

A collection of styles for Discord Web, intended to make layout and color adjustments to the UI introduced in the Visual Refresh so it looks more like its previous versions.

The main goal of this script is to undo some unpopular changes and take the Discord visual experience back to what the community is used to.

For the intended looks, the "Ash" theme is recommended, but any official theme should work fine, including light ones.

Being developed

  • Ensure the sustainability of the modifications.
  • Maybe figure out a way to embed a font explicitly in the script.

Features

  • A hotfix for the misaligned call icons on DMs.
  • No top bar in the browser app. Inbox and Help buttons appear next to the search bar.
  • A server list not obstructed by the top bar or the user panel.
  • Server icons are displayed as round unless they are focused or hovered.
  • Channel categories are displayed in all caps.
  • A user panel docked under the channel list.
  • Minor UI color tweaks to better mimic the old layout from before the refresh.

Requirements

  • Mozilla Firefox or Google Chrome. Recent versions are recommended.
  • Greasemonkey extension for Firefox, or Tampermonkey for Chrome.
