Under development, this tool makes and saves snapshots from your PC. It basically makes the task of pressing the PrintScreen key, pasting the captured image into some image editor and saving it, for you. Simple, all in just one click.

But not only that, you can also capture portions of your screen, using the translucent window to cover the desired area. If you don't even want to click the 'Capture' button, you can press F2 or F4 to save a partial or full snapshot.

Inspired from a friend's similar project in C#.

Being developed

  • Image filters
  • Image quality and customization options for each format

Features

  • Quick snapshot taking
  • Partial or Full screen capturing
  • Supports .jpg, .png, .gif and .bmp formats
  • Automatic save into a folder next to the jar's current location
  • Color themes powered by Substance (hence the filesize)
  • Stand-alone and portable

Requirements

  • Windows XP/Vista/7/8/10, Linux, Mac-OS X
  • Java Runtime Environment 7 or higher
  • Translucent windows support in AWT/Swing is recommended.
